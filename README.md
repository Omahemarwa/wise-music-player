# Wise Music Player

A high-fidelity offline music player featuring local media scanning, custom playlists, Now Playing screen with lyrics & queue, and rich audio playback.

## Features

- Full music playback controls (play, pause, next, previous, seek)
- Custom playlist creation and management
- Lyrics synchronization
- Queue management
- Local audio file import (mp3, flac, m4a, aac, wav)
- Procedural audio synthesis for demo tracks
- Audio visualization
- Mobile-first responsive design
- Dark theme with modern UI

## Run Locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:3000 in your browser

## Build for Production

```bash
npm run build
```

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Motion (Framer Motion)
- Web Audio API
